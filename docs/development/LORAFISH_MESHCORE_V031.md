# LoRaFish MeshCore Edition v0.3.1 — Fish sprite

This is intentionally a sprite-only update to the working v0.3 build.

Changes:
- Replaces the blocky solid fish with a larger outlined pixel-art fish.
- Rounded/tapered body.
- Forked tail.
- Dorsal and lower fins.
- Separate head/gill line.
- Visible eye and tiny mouth.
- Sparse scale pixels so the body remains readable on the monochrome OLED.
- Fully mirrored left/right versions for swimming animation.

The working MeshCore Companion BLE, radio path, stable pairing PIN, screen layout,
clock, stats and footer spacing from v0.3 are unchanged.
