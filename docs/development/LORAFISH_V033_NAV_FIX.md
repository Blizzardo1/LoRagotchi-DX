# LoRaFish v0.3.3 RF Monitor navigation fix
The RF page existed but was unreachable: short clicks on Options cycle option rows,
and the old Back action jumped directly to Aquarium.

Navigation now:
Aquarium -> Stats -> Clock -> Phone Pairing -> Options.
In Options, short-click to RF monitor and long-press to open it.
On RF Monitor, short-click returns to Aquarium.
