# LoRaFish MeshCore Edition v0.3 — UI polish

This is deliberately an interface-only revision of the working v0.2.2 MeshCore build.

- More breathing room between the header text and top separator.
- Larger, tapered pixel-art fish with tail, fins, snout and eye.
- Aquarium footer and seabed line moved safely above the OLED edge.
- Stats content kept within the visible 64-pixel height.
- Clock content shifted upward so the source/status line is not clipped.
- Pairing page tightened so its footer remains visible.
- Stable BLE PIN and the working MeshCore Companion/radio path from v0.2.2 are unchanged.
